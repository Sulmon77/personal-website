# Sulmon Bahati Otembo — Portfolio

Personal portfolio website for **Sulmon Bahati Otembo**, a full-stack developer in Nairobi, Kenya building SaaS products with M-Pesa & Paystack payments and Claude-powered AI automation.

**Live site:** [https://sulmon77.github.io/personal-website/](https://sulmon77.github.io/personal-website/)

## What's inside

- **FPL123** — fantasy football platform with paid gameweek competitions, league hosting and team analytics. Live at [fpl123.live](https://www.fpl123.live)
- **PropFlow** — property management SaaS with four Claude-powered agents, multi-tenant auth and real-time dashboards
- **ValueRadar** — product validation and buyer discovery with demand scoring

## Tech

Built as a dependency-free static site — hand-written HTML/CSS/JS, self-hosted Inter variable font, and vendored GSAP, ScrollTrigger and Lenis for motion. Dark Apple-inspired theme with a custom cursor, smooth scrolling, scroll-triggered reveals and a stacked project-card layout.

## Stack highlights

- React · Next.js · TypeScript · Node.js · PostgreSQL
- M-Pesa Daraja (STK Push) · Paystack · signed webhooks
- Claude API · multi-agent workflows · audit trails
- Docker Compose · Nginx · Vitest · Vercel
